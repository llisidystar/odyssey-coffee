# Odyssey

Интернет-магазин кофейни Odyssey на WordPress (экзаменационный проект ПМ.04).

## Что реализовано
- Тема Astra, фиксированное меню
- Главная страница
- Каталог товаров и корзина (WooCommerce)
- Новости с пагинацией
- Форма обратной связи (WPForms)
- Футер: копирайт, условия использования, соцсети
- Google Analytics (Site Kit)

## Как запустить
1. Скопировать папку в OSPanel (domains/shop/wordpress).
2. Создать базу данных `shop` в phpMyAdmin и импортировать файл `shop.sql`.
3. Создать `wp-config.php` из `wp-config-sample.php` и указать данные своей базы.
4. Открыть сайт по адресу shop.rus.
